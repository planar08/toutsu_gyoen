GITHUB PAGES · SETUP

設定官網訂房服務

官網與管理登入頁留在GitHub Pages，訂單儲存在您自己的Supabase專案。

先完成三個步驟

  1. 在 Supabase Dashboard 建立自己的專案，並在 SQL Editor 執行套件中的 database/install.sql。
  2. 在 Authentication → Users 建立 Email/Password 管理帳號，確認信箱已驗證。再修改並執行 database/authorize-admin.sql，授權該管理員。
  3. 到專案的 API Keys 找到 Publishable Key（sb_publishable_開頭），並取得專案網址。填入下方測試，下載設定檔後上傳GitHub。

本設定頁只產生您的網站設定檔，不會建立或修改Supabase專案。頁面不提供公開註冊管理員，管理權限只能由專案擁有者在SQL Editor授予。

填寫公開連線設定

只填公開的 Publishable Key。不可填入 Secret Key、service_role、資料庫密碼或管理密碼；下載的config.js將放在公開網站。

將下載的檔案放到 GitHub 儲存庫的 assets/config.js，等 Pages 更新完成。之後開啟 訂房頁及管理後台。

若出現「尚未授權管理員」，請完成管理帳號建立與授權SQL；若出現「功能不存在」，請先執行install.sql。設定完成前，網站不會假裝已收到訂房申請。
